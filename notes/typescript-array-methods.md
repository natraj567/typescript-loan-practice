# TypeScript Array Methods — Learning Notes

## 1. find()

Returns the first element that matches a condition, or `undefined` if no element matches.

## 2. filter()

Returns a new array containing all elements that match a condition.

## 3. forEach()

Executes a callback for each array element. It does not return a new transformed array.

## 4. Callback Functions

A callback is a function passed as an argument to another function.

## 5. Normal Functions and Arrow Functions

Practice writing both the main function and its callback using normal function syntax and arrow function syntax.

## 6. TypeScript Types

- `Loan[]` — array of loan objects
- `Loan` — one loan object
- `string` — text
- `number` — numeric value
- `boolean` — true or false
- `void` — no meaningful return value
- `Loan | undefined` — a loan or no matching loan
- `string | undefined` — a string or no available value
